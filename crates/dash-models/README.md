# dash-models

Model architectures for Dashmag, written once as Burn modules and run on any Burn device. Parameter paths follow the published PyTorch definitions, so their weights load without a conversion step. First: MobileNetV3-Small with any number of linear heads.

Part of [Dashmag](https://github.com/bayanasar/dashmag) — a runtime-agnostic
edge ML inference framework in Rust. See the repository for the full picture.

> **Status:** pre-alpha. APIs will change.
